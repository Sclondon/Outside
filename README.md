# Outside

A touch-first 3D character controller in the spirit of Inside: a small figure in a red shirt running
through a foggy grey-box course. Godot 4.7, built for phones and the web (the Scareathon arcade).

## Controls

- Touch: drag anywhere on the left half to move (a gentle push walks, a full push runs); tap the right
  half to jump, hold for a higher jump.
- Keyboard: WASD or arrows, Space to jump, Shift to walk. Gamepads work too.

## Layout

| File | What it does |
| --- | --- |
| `scripts/player.gd` | The controller: movement, jumping, stairs, pushing crates, respawn |
| `scripts/character_rig.gd` | Animates the model in code: gait, leg IK, lean, arms, landing |
| `scripts/touch_controls.gd` | Floating stick and jump area |
| `scripts/follow_camera.gd` | Fixed-angle side camera |
| `scripts/level.gd` | The test course, lighting and fog |
| `tools/build_character.py` | Builds `models/boy.glb` in Blender |

Tuning values are exported properties on the Player, Camera and TouchControls nodes.
Set `move_mode` to `SIDE_SCROLL` on the Player to lock movement to a line.

## The character model

`models/boy.glb` is generated by a Blender script (an editable copy is saved to `tools/boy.blend`):

```
blender --background --python tools/build_character.py
```

The joint positions in the script must match the constants at the top of `scripts/character_rig.gd`.

## Web build

```
godot --headless --path . --export-release Web build/index.html
```

`build/` is committed and served by GitHub Pages at https://sclondon.github.io/Outside/build/index.html
